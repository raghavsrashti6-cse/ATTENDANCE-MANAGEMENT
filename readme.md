# Attendance Management System

## 📌 Project Description

The **Attendance Management System** is a simple Python-based project designed to manage and track student attendance.

The system allows the user to:

* Add students
* Mark attendance as Present (P) or Absent (A)
* Calculate attendance percentage
* Display attendance records
* Check whether a student is eligible based on the attendance percentage

This project is created using basic Python concepts such as **dictionaries, functions, loops, conditional statements, and user input**.

---

## 🎯 Objectives

The main objectives of this project are:

1. To maintain student attendance records.
2. To reduce manual attendance calculations.
3. To calculate attendance percentage automatically.
4. To identify students who have attendance below the required percentage.
5. To practice Python programming concepts through a real-world application.

## ⚙️ Features

### 1. Add Student

The user can add a new student by entering the student's name.

### 2. Mark Attendance

The system allows the user to mark each student's attendance as:

* `P` – Present
* `A` – Absent

### 3. Calculate Attendance Percentage

The system calculates attendance using:

**Attendance Percentage = (Number of Present Days / Total Classes) × 100**

### 4. Attendance Status

The system displays the student's attendance status.

* **Eligible:** Attendance is 75% or above
* **Shortage:** Attendance is below 75%

### 5. Display Attendance

The system displays the student's name, total classes, present classes, attendance percentage, and status.
